# Te Leo · avisos

Lista pública de libros retirados de la app **Te Leo** (por ejemplo, tras
una reclamación de derechos de autor). La app descarga
[`retirados.txt`](retirados.txt) y oculta esos libros de las búsquedas
en bibliotecas públicas.

Te Leo no aloja ni distribuye libros: solo busca obras de dominio público
en bibliotecas públicas y las descarga directamente de ellas.

Para avisar de un libro, escribe a joe886529@gmail.com.
